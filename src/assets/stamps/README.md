# Cartomancer Stamp Assets Directory

Any image dropped into this folder or its subfolders is **automatically discovered** by the application with zero code changes required!

## Supported File Formats
- `.png` (Recommended: transparent background)
- `.svg` (Vector illustrations and line art)
- `.webp` (High efficiency transparent web images)
- `.jpg` / `.jpeg`

## Folder Structure & Automatic Categorization
Drop files into these subfolders to have them automatically sorted into the corresponding tool palette:

- `mountains/` → Mountains, hills, cliffs, volcanic peaks
- `trees/` → Trees, forests, groves, flora
- `settlements/` → Cities, villages, towns, hamlets
- `castles/` → Castles, fortresses, keeps, spires, watchtowers
- `nature_props/` → Cave entrances, monster lairs, ruins, dungeons
- `water_maritime/` → Ships, sea monsters, anchors, ports
- `decorations/` → Compass roses, banners, cartouches, corner ribbons
- `building_blocks/` → Modular walls, stone bridges, towers, gates
- `custom/` → Any general custom stamps

*(Note: If you create new subfolders with custom names, the app will automatically detect them and generate a corresponding tag!)*
